# Post by @kotetsu_0321 on X
2026-08-11
AIのDeep Researchは「調べる」は最強。でも、出てくるのはメリハリのない長文で「伝える」は最弱。正直、読まずに終わりがち。  
これを「会議に出せるレポート」に自動編集するskillsを作ったのでシェアします。  
動画はBefore/After比較で、中身は全く同じ。見やすさは一目瞭然。

インストール方法は  
Claude Code（デスクトップ版OK）にこの1行を貼るだけ。

「[https://t.co/ElNonr2JZb](https://t.co/ElNonr2JZb) の skills/deep-research-report を ~/.claude/skills/ にインストールして」

使い方は、調査結果（MDでもテキストでも）を渡して一言。

「この調査結果を deep-research-report でレポートにして」

・結論が先頭に来るピラミッド構造に組み替え  
・埋もれた数字をKPI・グラフに昇格、比較は表に  
・出典は消さず、巻末に一覧化  
・CLI派は npx skills add Ted0321/kotetsu-work-ai-skills@deep-research-report  
・ChatGPT派はSKILL.mdのコピペでも動きます

▼仕組み

デザイン以前に、Deep Researchの長文が読まれない原因は構造にあります。このスキルは中身を書き足さず、並べ替えて編集します。

・結論が最後 → 冒頭のサマリー3点に移動  
・数字が文中に埋没 → KPIとグラフに昇格  
・比較が文章のまま → 表とマトリクスに変換  
・出典がURLの羅列 → 図表ごとの出所＋巻末一覧に整理

図表化は勘でやらせません。  
「文章パターン→図表」の対訳表をスキルに持たせていて、「AがX%と最も高く、次いで…」なら横棒、「内訳は…」なら滝グラフ、「4段階の整理」ならステージ表、と機械的に変換されます。

▼こだわったポイント

AIに要約や変換をさせるとき、一番怖いのは「数字を盛る」ことです。

なのでこのスキルは「原文にない数値・事実を追加しない」を最上位ルールにして、出力の前に全数値を原文と照合させています。原文が「85%超」なら「85%超」のまま出ます。  
さらに、出典を「●複数出典で一致／◐単一出典／○予測・推計」の3段階で格付けして巻末に付記し、「この調査でわかっていないこと」も残論点として書かせます。  
AIのレポートが会議で信用されない原因は、盛り・出典不明・全部わかった風の3つ。逆にここを潰すと、AI製でもそのまま通ります。
