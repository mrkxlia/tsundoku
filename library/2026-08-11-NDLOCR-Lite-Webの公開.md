# Post by @yuta1984 on X
2026-08-11
NDLOCR-Lite をWebブラウザに移植した「NDLOCR-Lite Web」を公開しました。 [https://t.co/IJIIAewqUO](https://t.co/IJIIAewqUO) ブラウザ上で手軽に画像やPDFのOCR処理を試すことができます。  
Webアプリではありますがローカルで処理が完結するので、画像や認識テキストが外部に送信されることはありません（本家と同様）。 https://t.co/Vj0umGtKFH
