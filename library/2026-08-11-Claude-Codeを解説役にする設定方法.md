# Post by @AI_masaou on X
2026-08-11
CLAUDEmdに1行追加するだけで  
Claude Codeが「解説役」になる

体感だけど  
初心者にとって効果あるかも

✅ 前提

Claude Codeはリポジトリ直下の  
CLAUDEmdの指示に従う

ここに1行追加する

✅ 追加する1行

For every project, write a detailed FOR\[yourname\].md file that explains the whole project in plain language.

\[yourname\]は自分の名前に置き換える  
例：FORmasaomd、FORtaromd

✅ 何が生成されるか

プロジェクト全体の解説ドキュメントが自動で作られる

・技術アーキテクチャの概要  
・コードベースの構造説明  
・なぜその技術を選んだかの理由  
・よくあるバグと修正方法  
・落とし穴と回避方法  
・ベストプラクティス集

しかも退屈な技術文書じゃない  
類推や逸話を使って記憶に残りやすく書いてくれる

✅ なぜこれが効くか

普通の技術ドキュメントは  
「何をするか」しか書いてない  
FORファイルは「なぜそうなっているか」まで説明する

プログラミングで一番学びにくいのは「判断の理由」  
・なぜこのライブラリを選んだのか  
・なぜこの設計にしたのか  
・なぜこの書き方を避けたのか

この暗黙知が形式知になる  
初見コードで迷う時間が減る

✅ 具体的な使い方

1\. CLAUDEmdに上の1行を追加  
2\. Claude Codeでプロジェクトを作業  
3\. 自動的にFOR\[yourname\].mdが生成される  
4\. 作業後にそのファイルを読む

すべてのプロジェクトが学習教材になる

✅ 注意点

生成物は.gitignoreに追加推奨  
機密情報の混入やコミット事故を防ぐ

✅ 応用パターン

チーム開発なら各メンバー用に生成できる  
FORjuniormd → 新人向けの詳細解説  
FORseniormd → ベテラン向けの設計意図

オンボーディング資料が自動生成される状態

✅ 実体験から

初心者が伸び悩む最大の理由は  
「動くコードは書けるけど、なぜ動くか分からない」

この状態を解消するのがFORファイル  
動くコードと一緒に「理解」も生成される

まずは1プロジェクトで試してみてほしい
