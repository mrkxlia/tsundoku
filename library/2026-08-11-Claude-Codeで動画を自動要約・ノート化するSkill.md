【発見】  
あとで見ようと思ったLoomや会議の録画、溜まってませんか。  
[https://t.co/xX11FE7vuP](https://t.co/xX11FE7vuP)

動画を渡すだけで、Claude Codeが  
①文字起こし  
②重要フレーム抽出  
③要約ノート化  
までやってくれるコマンドが公開されていました🔥

・「/watch-video 動画のURL」と打つだけで、YouTube・Loom・Zoom録画・Vimeo・ローカル動画にほぼ対応  
・字幕/音声の取得→フレーム抽出→画像解析で重要シーンを判定、という流れを自動で実行  
・出力は文字起こし・重要フレームのメモ・構造化ノートの3点セットで、「セカンドブレイン」への保存も選べます

これは創業者・事業運営者向けに公開されている無料オープンソースのSkill集「Maker Skills」に含まれる1つです。

投稿者本人は、チャンネル開設前の下調べとしてYouTube動画100本の分析、クライアントから届くLoom動画や通話録画の確認に使っていると紹介していました。

動画100本を「見る」時間が、まるごとスキップできるということです。

そのほか、効率化できるSkillを記事にまとめています。
