## ホワイトペーパー

SNIA ホワイトペーパー（翻訳版）「DNA データストレージ技術レビュー」を掲載いたしました。

本書は、ストレージ・アーキテクチャやメモリ・アーキテクチャを担当している専門家を対象に、最新のDNA Data Storageについて解説したものです。

原典（2025年6月発行：DNA Data Storage Technology Review）は以下を参照ください。  
原文はこちら (snia.org)： [https://www.snia.org/educational-library/dna-data-storage-technology-review-2025](https://www.snia.org/educational-library/dna-data-storage-technology-review-2025)

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2026/03/SNIA-DNA-Data-Storage-Technology-Review-v1.0_J-rev20260311.pdf)

SNIA ホワイトペーパー（翻訳版）「SNIA永続メモリ性能試験仕様の概要」を掲載いたしました。

本書は、ストレージ・アーキテクチャやメモリ・アーキテクチャを担当している試験開発の専門家を対象に、最新のSNIA Performance Test Specification(PTS) v1.0.1について解説したものです。

原典（2020年10月発行：Introduction to SNIA Persistent Memory Performance Test Specification）は以下を参照ください。  
原文はこちら： [Intro-SNIA-PM-Performance-Test-Spec-TWP-2020-Oct.pdf (snia.org)](https://www.snia.org/sites/default/files/technical_work/Whitepapers/Intro-SNIA-PM-Performance-Test-Spec-TWP-2020-Oct.pdf)

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2024/11/Intro-SNIA-PM-Performance-Test-Spec-TWP-2020-Oct_J.pdf)

SNIA ホワイトペーパー（翻訳版）「NVMe® over Fabrics（NVMe-oF™）の最適化」を掲載いたしました。

本書は、様々なワークロード（人工的なワークロードと現実世界のワークロード）について、NVMe® over Fabrics（NVMe-oF™）のRDMA（iWARPとRoCEv2）トランスポートとTCPトランスポートを使用して3D XPointと3D NANDの性能比較を説明したものです。

原典（2021年04月発行： Optimizing NVMe® over Fabrics (NVMe-oF™)）は以下を参照ください。  
原文はこちら： [snia-optimizing-nvme-over-fabrics-nvme-of.pdf (snia.org)](https://www.snia.org/sites/default/files/education/snia-optimizing-nvme-over-fabrics-nvme-of.pdf)

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2024/11/snia-optimizing-nvme-over-fabrics-nvme-of_J.pdf)

SNIA ホワイトペーパー（翻訳版）「マルチクラウド ・ホワイトペーパー」を掲載いたしました。

本書は、クラウド内でのデータの保存に関するマルチクラウド戦略の導入と、そのメリットについて説明したものです。また、SNIA Cloud Data Management Interface（CDMI™）v2.0についても解説しています。

原典（2022年10月発行：Multi-cloud White Paper）は以下を参照ください。  
原文はこちら： [SNIA-Multi-Cloud-Technical-White-Paper.pdf (snia.org)](https://www.snia.org/sites/default/files/technical-work/whitepapers/SNIA-Multi-Cloud-Technical-White-Paper.pdf)

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2024/11/Multi-cloud-White-Pape_J.pdf)

SNIAホワイトペーパー「ストレージ初学者のためのホワイトペーパー」

本書は、IT企業に入社して、初めてストレージを利用又は開発するエンジニアをターゲットとして、個々の技術に深入りするよりも、ストレージ技術の幅広い分野について一通り理解できることを目的にSNIA日本支部技術委員会が作成したものです。

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2024/06/Storage_Beginners_White_Paper.pdf)

SNIA ホワイトペーパー（翻訳版）「クラウド、データセンタ、およびエンタープライズ・ストレージのためのストレージ・デバイス・レベルの電力効率測定」

本書は、ストレージ・デバイス・レベル（個別HDD、SSD）の電力効率のテスト方法、デバイステスト装置、ワークロードの使用法、メトリクスの計算、およびデバイステスト結果について説明したものです。

原典（2022年10月発行： Storage Device-Level Power Efficiency Measurement for Cloud, Datacenter & Enterprise Storage）は以下を参照ください。  
原文はこちら： [StorageDeviceLevelPowerEfficiencyMeasurement-28Oct2022.pdf (snia.org)](https://www.snia.org/sites/default/files/technical-work/whitepapers/StorageDeviceLevelPowerEfficiencyMeasurement-28Oct2022.pdf)

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2023/03/StorageDeviceLevelPowerEfficiencyMeasurement-28Oct2022_J.pdf)

SNIA ホワイトペーパー（翻訳版）「エネルギー効率の良いデータ・センター・ストレージ： ストレージ製品の電力効率の評価」を掲載いたしました。

本書はSNIAやグリーン・グリッドの会員企業が電力効率を評価する場合にどのような基準とテスト指標を使用すべきかを解説したもので、ストレージ装置のエネルギー消費効率と、そのストレージ装置の構成と測定に使われるワークロードの関係を分析しています。

原典（2022年7月発行： Energy Efficient Data Center Storage）は以下を参照ください。  
原文はこちら： [WP#86 Energy Efficient Data Center Storage 2022-06-21 WI#20-003.pdf (snia.org)](https://www.snia.org/sites/default/files/emerald/External_Links/WP%2386%20Energy%20Efficient%20Data%20Center%20Storage%202022-06-21%20WI%2320-003.pdf)

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2023/01/WP_86_Energy_Efficient_Data_Center_Storage.pdf)

SNIA ホワイトペーパー（翻訳版）「SNIA Emerald™ V4分類」を掲載いたしました。

本書はストレージシステムの電力効率測定方法を規定したSNIA Emerald™ 電力効率測定仕様V4で定義されるストレージ分類について、前バージョンSNIA Emerald™電力効率測定仕様V3.0.3からの変更点、分類属性の拡張内容と、その背景を説明したものです。

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2020/12/SNIA-Emerald-V4-Storage-Taxonomy_J.pdf)

SNIA ホワイトペーパー（翻訳版）「ストレージセキュリティ：データ保護」を掲載いたしました。

ストレージセキュリティは、ストレージシステムとインフラストラクチャだけでなく、それらに保存されたデータも保護するための物理的、技術的、および管理的規制の適用に関係します。データ保護の認識を高めるために、このホワイトペーパーでは、ISO/IEC 27040 内の関連するデータ保護ガイダンスの概要を示し、それを踏まえて、データ分類、保有と保管、データ認証性、データ廃棄などのテーマについて説明します。  
原文はこちら： [https://www.snia.org/education/whitepapers/security-wp](https://www.snia.org/education/whitepapers/security-wp)

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2019/06/Data-Protection_j.pdf)

SNIAホワイトペーパー(翻訳版)「エネルギー効率の良いデータ・センター・ストレージ：ストレージ製品のエネルギー効率の評価に対する **SNIA Emerald** ™分析ツールの有用性」を掲載いたしました。

本書はSNIAやグリーン・グリッドの会員企業が、SNIA EmeraldTMバージョン2.0の指定する方法で測定したストレージ装置のエネルギー消費効率と、それを得たストレージ装置の構成と、測定に使われるワークロードの関係を分析したものです。

※資料のダウンロードはこちら→ [日本語版.PDF](https://www.snia-j.org/cmm/images/2021/08/GSI_WhitePaper_2018_1_V1J.pdf)

SNIAホワイトペーパー「Storage Security: An overview as applied to storage management」  
を掲載いたしました。

SNIA Technical White Paper（翻訳版）「ストレージセキュリティ：ストレージ管理に関する概要」 （英題：Storage Security: An overview as applied to storage management）を掲載しました。

本書は、SNIAセキュリティ技術分科会がISO/IEC 27040:2015, Information technology – Security techniques – Storage security内の重要なトピックの紹介と概要を提供するために作成した一連のホワイトペーパーの1つです。  
本ホワイトペーパーでは、ストレージセキュリティに関係する重要なセキュリティ概念の概要を示し、ストレージ管理に該当する標準内のセキュリティガイダンスを概説します。また、組織の特定のニーズを満たすストレージ管理セキュリティプログラムを開発する場合の追加のSNIA ガイダンスも提供します。今回翻訳したホワイトペーパーをご一読いただき、ストレージセキュリティに関する理解を深めていただく一助になれば幸いです。

※資料のダウンロードはこちら→　 [日本語版.PDF](https://www.snia-j.org/cmm/images/wh/j-overview.pdf) / [英語版.PDF](https://www.snia-j.org/cmm/images/wh/e-overview.pdf)

SNIAホワイトペーパー「Hyperscaler Storage」

本書は、ハイパースケール型のストレージシステムに対する新しい要件と、Tail Latency, Depopulation, Streams, Advanced Background Operation, Rapid RAID Rebuild, I/O Hintといったそれらを解決する技術概要を紹介します。これらの技術の一部は、T10, T13, NVMeなどによって標準化の議論が始まっています。本ホワイトペーパーをご一読いただき、ハイパースケール型のストレージシステムに対する理解を深めていただく一助になれば幸いです。
